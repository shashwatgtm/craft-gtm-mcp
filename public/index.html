CRAFT GTM

Go-to-market planning tools built on the CRAFT framework

CRAFT GTM gives Claude eight planning tools for B2B go-to-market work: a product-market fit scorecard, launch plans, customer interview guides, retention playbooks, partner programs, crisis playbooks, competitive battle cards and a CRAFT review of any GTM document. Every tool turns the details you give it into a structured plan.

Connect

Server URL

https://craft-gtm-mcp.netlify.app/mcp

Transport: Streamable HTTP (stateless, JSON responses). Authentication: none. Send MCP JSON-RPC messages with POST; other methods return 405, which is expected.

Claude (web, desktop and mobile)

  1. Open Customize, then Connectors, then Add custom connector.
  2. Name: CRAFT GTM. MCP server URL: https://craft-gtm-mcp.netlify.app/mcp.
  3. Choose no sign-in, then Add. Turn the connector on for a chat with the + menu.

Claude Code

claude mcp add --transport http craft-gtm https://craft-gtm-mcp.netlify.app/mcp

Run it locally instead (npm, stdio)

npx -y @shashwatgtmalpha/craft-gtm-mcp

The npm package and this hosted server run the same code.

Tools

All tools only build text from the inputs you give them. They are marked read-only: they store nothing, change nothing and call no outside service.

ToolTitleWhat it doesRequired inputs
pmf_scorecardPMF ScorecardGenerate a Product-Market Fit scorecard. Parses the metrics you provide (MRR, churn, NPS, CAC, LTV, retention, activation and similar) and scores each dimension against built-in benchmark ranges.product, target_market, current_metrics
launch_commanderLaunch CommanderGenerate a context-aware launch plan. Have a date? Get a detailed timeline. Still planning? Enter 'TBD' or 'Q2 2025' for a flexible plan.product_feature, launch_type, target_segments, goals
customer_interview_kitCustomer Interview KitGenerate interview guides that ADAPT based on interview type, industry, and product complexity. Includes synthesis templates.interview_type, product_context, target_persona
retention_playbookRetention PlaybookGenerate retention strategies. Has DISCOVERY MODE - if you don't know WHY people churn, get a churn analysis framework first.customer_segment, business_model, current_churn_rate
partner_architectPartner ArchitectDesign partner programs that ADAPT based on partner model type. Different structures for resellers vs referrals vs integrations vs affiliates.company, product, partner_model, partner_goals, your_deal_size
crisis_plannerCrisis PlannerGenerate crisis playbooks. Know your risks? Get specific playbooks. Not sure what to plan for? We'll suggest the top crises for your industry.company, industry, customer_base, data_sensitivity
competitive_intelCompetitive IntelGenerate battle cards. If you know your strengths/weaknesses, get complete battle cards. If you only know competitors and win/loss stories, we'll derive your positioning.your_product, competitors
craft_gtm_analyzerCRAFT GTM AnalyzerAnalyze a GTM document against the CRAFT framework. Parses the content, identifies gaps, scores each dimension and suggests sections to add.document_content, document_type

Example prompts

  1. Use CRAFT GTM to score our product-market fit. Product: a scheduling tool for clinics, target market: SMB SaaS. Metrics: MRR $40K, churn 4% monthly, NPS 38, CAC $600, LTV $4,200.
  2. Build a launch plan with CRAFT GTM for our new analytics add-on, a feature launch on 2026-11-15, for mid-market finance teams. Goals: 300 trials and $80K pipeline.
  3. Create a customer interview kit for churn interviews with operations managers at SaaS companies about our workflow automation product.
  4. Use CRAFT GTM to make battle cards for our product Acme Notes against Competitor A and Competitor B. Recent wins: faster setup. Recent losses: missing SSO.

Troubleshooting

  • 405 Method not allowed: you opened the server URL in a browser or sent a GET. Use an MCP client, which sends POST.
  • 429 Too many requests: the server allows 300 requests per minute from one address. Wait a minute and try again.
  • "Missing required input": the tool was called without one of the required inputs listed above.
