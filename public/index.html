CRAFT GTM

GTM planning tools built on the CRAFT framework

Setup and toolsQuestionsPrivacySource codeAll connectors

CRAFT GTM gives Claude eight planning tools for B2B go-to-market work: a product-market fit scorecard, launch plans, customer interview guides, retention playbooks, partner programs, crisis playbooks, competitive battle cards and a CRAFT review of any GTM document. Every tool turns the details you give it into a structured plan.

Connect

Server URL

https://craft-gtm.gtmhelix.com/mcp

Transport: Streamable HTTP (stateless, JSON responses). Authentication: none. Send MCP JSON-RPC messages with POST; other methods return 405, which is expected.

Claude (web, desktop and mobile)

  1. Open Customize, then Connectors, then Add custom connector.
  2. Name: CRAFT GTM. MCP server URL: https://craft-gtm.gtmhelix.com/mcp.
  3. Choose no sign-in, then Add. Turn the connector on for a chat with the + menu.

Claude Code

claude mcp add --transport http craft-gtm https://craft-gtm.gtmhelix.com/mcp

Run it locally instead (npm, stdio)

npx -y @shashwatgtmalpha/craft-gtm-mcp

The npm package and this hosted server run the same code.

Tools

All tools only build text from the inputs you give them. They are marked read-only: they store nothing, change nothing and call no outside service.

Questions and answers

What is CRAFT GTM?

CRAFT GTM gives Claude eight planning tools for B2B go-to-market work: a product-market fit scorecard, launch plans, customer interview guides, retention playbooks, partner programs, crisis playbooks, competitive battle cards and a CRAFT review of any GTM document. Every tool turns the details you give it into a structured plan.

How do I connect CRAFT GTM to Claude?

In Claude, open Customize, then Connectors, then Add custom connector. Name it CRAFT GTM, paste the server URL https://craft-gtm.gtmhelix.com/mcp, choose no sign-in and select Add. In Claude Code run: claude mcp add --transport http craft-gtm https://craft-gtm.gtmhelix.com/mcp

Does CRAFT GTM need an account, and what does it cost?

No account or sign-in is needed, and there is no charge. The server is public and every tool is read-only.

Which tools does CRAFT GTM include?

8 tools: PMF Scorecard, Launch Commander, Customer Interview Kit, Retention Playbook, Partner Architect, Crisis Planner, Competitive Intel, CRAFT GTM Analyzer.

What data does CRAFT GTM keep?

None. Each call is answered from the inputs you give it, and the server stores and logs nothing. Netlify, the host, keeps its own request logs. See the privacy policy.

Can I run CRAFT GTM on my own computer?

Yes. Run npx -y @shashwatgtmalpha/craft-gtm-mcp to use the same tools locally over stdio; nothing is sent to us.

Who built CRAFT GTM?

Shashwat Ghosh, founder of Helix GTM Consulting, a GTM Alpha consultant, AI GTM expert and fractional CMO with 24+ years in B2B and 10+ years of fractional experience.

Troubleshooting

  • 405 Method not allowed: you opened the server URL in a browser or sent a GET. Use an MCP client, which sends POST.
  • 429 Too many requests: the server allows 300 requests per minute from one address. Wait a minute and try again.
  • "Missing required input": the tool was called without one of the required inputs listed above.
