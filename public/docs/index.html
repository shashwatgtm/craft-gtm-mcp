For developers

CRAFT GTM docs

The MCP address, the REST API behind the web forms, and every field of all 8 tools.

By Shashwat Ghosh, Co-Founder and Fractional CMO, Helix GTM Consulting · Last updated 29 September 2026

Try these prompts

  1. Use CRAFT GTM to score our product-market fit. Product: a scheduling tool for clinics, target market: SMB SaaS. Metrics: MRR $40K, churn 4% monthly, NPS 38, CAC $600, LTV $4,200.
  2. Build a launch plan with CRAFT GTM for our new analytics add-on, a feature launch on 2026-11-15, for mid-market finance teams. Goals: 300 trials and $80K pipeline.
  3. Create a customer interview kit for churn interviews with operations managers at SaaS companies about our workflow automation product.
  4. Use CRAFT GTM to make battle cards for our product Acme Notes against Competitor A and Competitor B. Recent wins: faster setup. Recent losses: missing SSO.

MCP server

  • Address: https://craft-gtm.gtmhelix.com/mcp (Streamable HTTP, stateless, JSON responses). GET returns 405 by design.
  • Authentication: none. Every tool is marked read-only (readOnlyHint: true, destructiveHint: false) and has a title.
  • Rate limit: 300 requests per minute per IP address. Server: craft-gtm-mcp version 2.2.11.
  • Limits: 262,144 bytes per call; text fields up to 4,000 characters, except the document fields document_content (CRAFT GTM Analyzer) and competitor_details (Competitive Intel), which take up to 100,000; one call per request (no batches). A call over a limit is refused before the tool runs.
  • Local use: npx -y @shashwatgtmalpha/craft-gtm-mcp runs these tools over stdio (npm can lag behind this site until a new version is published).

REST API (used by the web forms)

Send POST https://craft-gtm.gtmhelix.com/api/tools/<tool name> with a JSON body {"input": {...}}. The answer is JSON: {"ok": true, "tool": "...", "title": "...", "text": "..."}, where text is the same Markdown the MCP tool returns. The endpoint calls the same server code as the MCP address.

Terminal
curl -s -X POST https://craft-gtm.gtmhelix.com/api/tools/pmf_scorecard \
  -H "Content-Type: application/json" \
  -d '{"input": {"product": "ExampleCo Scheduler, scheduling software for clinics", "target_market": "smb_saas", "current_metrics": "MRR: $40K, Churn: 4%, NPS: 38, CAC: $600, LTV: $4200, Retention: 90%", "time_in_market": "1_2_years"}}'
  • Errors: 400 with errors (missing or invalid fields), 404 for an unknown tool, 405 for methods other than POST, 413 above 32,000 bytes, 422 when the tool itself refuses the input (ok is false and error holds the tool's message), 429 when the rate limit is reached, 500 if the tool fails.
  • Limits: 30 requests per minute per IP address; the whole request up to 32,000 bytes; top-level text fields up to 6,000 characters and top-level lists up to 50 items.
  • Forms without JavaScript post application/x-www-form-urlencoded and get an HTML page back.
  • Nothing is stored and the input is not logged (see Privacy).

Tool reference

Generated from the server's own input schemas, version 2.2.11.

PMF Scorecard

pmf_scorecard

Generate a Product-Market Fit scorecard. Parses the metrics you provide (MRR, churn, NPS, CAC, LTV, retention, activation and similar) and scores each dimension against built-in benchmark ranges. Open the form.

FieldTypeRequiredAllowed valuesMeaning
productstringyesProduct name and brief description
target_marketstringyesenterprise_saas, smb_saas, consumer, marketplace, fintech, healthtech, otherTarget market segment (e.g., 'Enterprise SaaS', 'SMB', 'Consumer')
current_metricsstringyesYour current metrics (will be PARSED). Include any of: MRR, ARR, churn rate, NPS, CAC, LTV, retention rate, activation rate, DAU/MAU, trial conversion, revenue growth. Example: 'MRR: $50K, Churn: 3%, NPS: 45, CAC: $500, LTV: $3000, Retention: 92%'
time_in_marketstringnopre_launch, 0_6_months, 6_12_months, 1_2_years, 2_plus_yearsHow long the product has been in market (shown in the scorecard)
customer_feedbackstringnoOptional: Qualitative feedback themes (e.g., 'Users love X but struggle with Y')
