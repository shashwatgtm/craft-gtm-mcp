For developers

CRAFT GTM docs

For developers and marketing operations teams. The decision: how to call CRAFT GTM from your own code or assistant.

Connect to the 10 MCP tools, check their input fields or call the REST API behind the web forms.

Pick a tool

By Shashwat Ghosh, Co-Founder and Fractional CMO, Helix GTM Consulting · Last updated 15 November 2026

Try these prompts

  1. Use CRAFT GTM to score our product market fit. Product: our field sales app for consumer goods brands and their distributors; target market: enterprise SaaS. Metrics: MRR $60K, churn 1.5% monthly, NPS 44, CAC $9,000, LTV $72,000.
  2. Build a launch plan with CRAFT GTM for our new order suggestions for field reps, a feature launch on 2026-11-15, for packaged food and personal care brands. Goals: 40 brand demos and $300K pipeline.
  3. Create a customer interview kit for churn interviews with heads of sales operations at consumer goods brands about our field sales app.
  4. Use CRAFT GTM to make battle cards for our field sales app against the free sales app in the distributor management system and paper order books. Recent wins: offline order capture. Recent losses: buyers wanted billing and sales in one system.

MCP server

  • Address: https://craft-gtm.gtmhelix.com/mcp (Streamable HTTP, stateless, JSON responses). GET returns 405 by design.
  • Authentication: none. Every tool is marked read only (readOnlyHint: true, destructiveHint: false) and has a title.
  • Rate limit: 300 requests per minute per IP address. Server: craft-gtm-mcp version 2.2.24.
  • Limits: 262,144 bytes per call; text fields up to 4,000 characters, except the document fields document_content (CRAFT GTM Analyzer) and competitor_details (Competitive Intel), which take up to 100,000 characters; one call per request (no batches). A call over a limit is refused before the tool runs.
  • Local stdio: npx -y @shashwatgtmalpha/craft-gtm-mcp. Latest npm version on 15 November 2026: 2.2.23.

REST API (used by the web forms)

Send POST https://craft-gtm.gtmhelix.com/api/tools/<tool name> with a JSON body {"input": {...}}. The answer is JSON: {"ok": true, "tool": "...", "title": "...", "text": "..."}, where text is the same Markdown the MCP tool returns. The endpoint calls the same server code as the MCP address.

Terminal
curl -s -X POST https://craft-gtm.gtmhelix.com/api/tools/pmf_scorecard \
  -H "Content-Type: application/json" \
  -d '{"input": {"product": "our field sales app for consumer goods brands and their distributors", "target_market": "enterprise_saas", "current_metrics": "MRR: $60K, Churn: 1.5%, NPS: 44, CAC: $9000, LTV: $72000, Retention: 95%", "time_in_market": "1_2_years"}}'
  • Errors: 400 with errors (missing or invalid fields), 404 for an unknown tool, 405 for methods other than POST, 413 above 32,000 bytes, 422 when the tool itself refuses the input (ok is false and error holds the tool's message), 429 when the rate limit is reached, 500 if the tool fails.
  • Limits: 30 requests per minute per IP address; the whole request up to 32,000 bytes; top level text fields up to 6,000 characters and top level lists up to 50 items.
  • Forms without JavaScript post application/x-www-form-urlencoded and get an HTML page back.
  • Inputs and answers are not stored, and the input is not logged (see Privacy).

PMF Scorecard

pmf_scorecard

Helps you decide whether you have product market fit and whether to scale: it takes your product, target market and current metrics (MRR, ACV, churn, NPS, CAC, LTV, retention, activation and similar) and returns a scorecard that scores each dimension against example benchmark ranges. It also gives priority actions and the data gaps to fill, reads the business model from your inputs, leaves the activation score out for services, connectivity and investment businesses, and quotes and answers your customer feedback.

Ask the user to confirm it when it differs from the product description. The selected benchmark and its stated fallback ranges are used; the output explains conflicts. The separate sector choice controls sector notes.
current_metricsstringyesYour current metrics, written as text (the tool reads the figures from it). Include any of: MRR, ARR, ACV, churn rate, NPS, CAC, LTV, retention rate, activation rate, DAU/MAU, trial conversion, revenue growth. Example: 'MRR: $50K, Churn: 3%, NPS: 45, CAC: $500, LTV: $3000, Retention: 92%'. A figure that no rule scores is listed as not scored
time_in_marketstringnopre_launch, 0_6_months, 6_12_months, 1_2_years, 2_plus_yearsHow long the product has been in market (shown in the scorecard)

How to read the answer

Both the MCP server and the REST endpoint return the same structured Markdown text for a given input object. Inside the returned Markdown, scores are calculated from fixed rules, bracketed placeholders mark missing facts, and any unprovided benchmark is labelled as an example figure.
