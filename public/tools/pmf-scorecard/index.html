PMF Scorecard

Generate a Product-Market Fit scorecard. Parses the metrics you provide (MRR, churn, NPS, CAC, LTV, retention, activation and similar) and scores each dimension against built-in benchmark ranges.

By Shashwat Ghosh, Co-Founder and Fractional CMO, Helix GTM Consulting · Last updated 25 September 2026

What do I need to run PMF Scorecard?

Free, no sign-up, no account. A web browser is enough; the answer comes back in a second or two.

InputRequired?What to enter
ProductRequiredProduct name and brief description
Target marketRequiredTarget market segment (e.g., 'Enterprise SaaS', 'SMB', 'Consumer') Allowed: enterprise saas, smb saas, consumer, marketplace, fintech, healthtech, other.
Current metricsRequiredYour current metrics (will be PARSED). Include any of: MRR, ARR, churn rate, NPS, CAC, LTV, retention rate, activation rate, DAU/MAU, trial conversion, revenue growth. Example: 'MRR: $50K, Churn: 3%, NPS: 45, CAC: $500, LTV: $3000, Retention: 92%'
Time in marketOptionalHow long the product has been in market (shown in the scorecard) Allowed: pre launch, 0 6 months, 6 12 months, 1 2 years, 2 plus years.
Customer feedbackOptionalOptional: Qualitative feedback themes (e.g., 'Users love X but struggle with Y')
  1. Fill in the required inputs above in the form below, or press Fill in a tested example.
  2. Press Run PMF Scorecard.
  3. Read the result on this page, then copy it and edit it before you use it.

Who is PMF Scorecard not ideal for?

  • Anyone who cannot give the required inputs (Product, Target market, Current metrics); the answer is built only from them.
  • Teams that want finished, publish-ready plans: each tool returns a structured draft, with placeholders where your inputs gave no fact.
  • Anyone who needs live market or competitor data: the tools look nothing up and use only what you type.

How do I use PMF Scorecard from Claude?

Connect CRAFT GTM once (see Connect), then ask in plain words. A prompt built from the tested example:

Use CRAFT GTM's PMF Scorecard tool. product: ClinicFlow, scheduling software for clinics; target market: smb saas; current metrics: MRR: $40K, Churn: 4%, NPS: 38, CAC: $600, LTV: $4200, Retention: 90%; time in market: 1 2 years.

MCP tool name: pmf_scorecard. REST: POST https://craft-gtm.gtmhelix.com/api/tools/pmf_scorecard with this JSON body (see Docs):

{
  "input": {
    "product": "ClinicFlow, scheduling software for clinics",
    "target_market": "smb_saas",
    "current_metrics": "MRR: $40K, Churn: 4%, NPS: 38, CAC: $600, LTV: $4200, Retention: 90%",
    "time_in_market": "1_2_years"
  }
}

How does PMF Scorecard work?

It applies fixed rules in the CRAFT GTM code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
