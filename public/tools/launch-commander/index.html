Launch Commander

Generate a context-aware launch plan. Have a date? Get a detailed timeline. Still planning? Enter 'TBD' or 'Q2 2025' for a flexible plan.

Run Launch Commander in your browser

Required: Product feature, Launch type, Target segments, Goals. Fields marked optional can be left empty.

What you're launching (product/feature name and description)

Target launch date. Accepts: 'YYYY-MM-DD', 'Q1 2025', 'March 2025', or 'TBD' for planning mode

Type of launch determines plan complexity

Target customer segments (comma-separated)

Launch success metrics (e.g., '500 signups, $50k pipeline, 10% trial conversion, 1000 downloads')

Optional: Marketing channels available (comma-separated). E.g., 'email, linkedin, blog, webinar, PR, paid_ads, community'

Marketing/GTM team size affects task distribution

Budget affects recommended tactics

Result

Use it from Claude or another assistant

Connect CRAFT GTM once (see Connect), then ask in plain words. A prompt built from the tested example:

Use CRAFT GTM's Launch Commander tool. product feature: Analytics add-on; launch date: 2026-11-15; launch type: feature launch; target segments: mid-market finance teams, operations leaders; goals: 300 trials, $80K pipeline; team size: small 2 5; budget level: moderate.

MCP tool name: launch_commander. REST: POST https://craft-gtm.gtmhelix.com/api/tools/launch_commander (see Docs).

How this tool works

It applies fixed rules in the CRAFT GTM code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
