Who is Partner Architect not ideal for?

  • Anyone who cannot give the required inputs (Company, Product, Partner model, Partner goals, Your deal size); the answer is built only from them.
  • Teams that want finished, publish-ready plans: each tool returns a structured draft, with placeholders where your inputs gave no fact.
  • Anyone who needs live market or competitor data: the tools look nothing up; they work from what you type, and anything they add themselves is marked as an example, a suggestion or a placeholder.

How do I use Partner Architect from Claude?

Connect CRAFT GTM once (see Connect), then ask in plain words. A prompt built from the tested example:

Use CRAFT GTM's Partner Architect tool. company: Acme Notes; product: Team knowledge base; partner model: referral; partner goals: 20% of new revenue from partners; your deal size: $5000 ACV; partner support capacity: moderate.

MCP tool name: partner_architect. REST: POST https://craft-gtm.gtmhelix.com/api/tools/partner_architect with this JSON body (see Docs):

{
  "input": {
    "company": "Acme Notes",
    "product": "Team knowledge base",
    "partner_model": "referral",
    "partner_goals": "20% of new revenue from partners",
    "your_deal_size": "$5000 ACV",
    "partner_support_capacity": "moderate"
  }
}

How does Partner Architect work?

It applies fixed rules in the CRAFT GTM code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server call the same tool code, so the same input gives the same answer in both.
