Competitive Intel

Generate battle cards. If you know your strengths/weaknesses, get complete battle cards. If you only know competitors and win/loss stories, we'll derive your positioning.

By Shashwat Ghosh, founder of Helix GTM Consulting · Last updated 25 September 2026

How do I run Competitive Intel in my browser?

Required: Your product, Competitors. Fields marked optional can be left empty.

Your product name and brief description

Competitor names (comma-separated). Will generate battle card for EACH

OPTIONAL: What you do better (comma-separated). Will be DERIVED from wins/losses if not provided

OPTIONAL: Where competitors beat you (comma-separated). Will be DERIVED from wins/losses if not provided

Optional: Any known details about competitors. E.g., 'Competitor A is cheaper, Competitor B targets enterprise'

Sales objections you hear (comma-separated). E.g., 'too expensive, missing X feature, competitor has better Y'

Why customers chose you over competitors - will be used to DERIVE strengths

Why you lost deals to competitors - will be used to DERIVE weaknesses

Result

How do I use Competitive Intel from Claude?

Connect CRAFT GTM once (see Connect), then ask in plain words. A prompt built from the tested example:

Use CRAFT GTM's Competitive Intel tool. your product: Acme Notes, a team knowledge base; competitors: Competitor A, Competitor B; recent wins: faster setup, better search; recent losses: missing SSO.

MCP tool name: competitive_intel. REST: POST https://craft-gtm.gtmhelix.com/api/tools/competitive_intel (see Docs).

How does Competitive Intel work?

It applies fixed rules in the CRAFT GTM code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
