Generate battle cards. If you know your strengths/weaknesses, get complete battle cards. If you only know competitors and win/loss stories, we'll derive your positioning.

Who is Competitive Intel not ideal for?

  • Anyone who cannot give the required inputs (Your product, Competitors); the answer is built only from them.
  • Teams that want finished, publish-ready plans: each tool returns a structured draft, with placeholders where your inputs gave no fact.
  • Anyone who needs live market or competitor data: the tools look nothing up; they work from what you type, and anything they add themselves is marked as an example, a suggestion or a placeholder.

How do I use Competitive Intel from Claude?

Connect CRAFT GTM once (see Connect), then ask in plain words. A prompt built from the tested example:

Use CRAFT GTM's Competitive Intel tool. your product: Acme Notes, a team knowledge base; competitors: Competitor A, Competitor B; recent wins: faster setup, better search; recent losses: missing SSO.

MCP tool name: competitive_intel. REST: POST https://craft-gtm.gtmhelix.com/api/tools/competitive_intel with this JSON body (see Docs):

{
  "input": {
    "your_product": "Acme Notes, a team knowledge base",
    "competitors": "Competitor A, Competitor B",
    "recent_wins": "faster setup, better search",
    "recent_losses": "missing SSO"
  }
}

How does Competitive Intel work?

It applies fixed rules in the CRAFT GTM code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server call the same tool code, so the same input gives the same answer in both.
