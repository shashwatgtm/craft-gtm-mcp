Communication Principles

Who is Crisis Planner not ideal for?

  • Anyone who cannot give the required inputs (Company, Industry, Customer base, Data sensitivity); the answer is built only from them.
  • Teams that want finished, publish-ready plans: each tool returns a structured draft, with placeholders where your inputs gave no fact.
  • Anyone who needs live market or competitor data: the tools look nothing up and use only what you type.

How do I use Crisis Planner from Claude?

Connect CRAFT GTM once (see Connect), then ask in plain words. A prompt built from the tested example:

Use CRAFT GTM's Crisis Planner tool. company: Acme Notes; industry: saas; customer base: b2b smb; data sensitivity: medium business data; company size: startup under 50.

MCP tool name: crisis_planner. REST: POST https://craft-gtm.gtmhelix.com/api/tools/crisis_planner with this JSON body (see Docs):

{
  "input": {
    "company": "Acme Notes",
    "industry": "saas",
    "customer_base": "b2b_smb",
    "data_sensitivity": "medium_business_data",
    "company_size": "startup_under_50"
  }
}

How does Crisis Planner work?

It applies fixed rules in the CRAFT GTM code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
