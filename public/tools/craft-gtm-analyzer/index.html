Who is the CRAFT GTM Analyzer tool not ideal for?

  • Anyone who cannot give the inputs listed above, because the answer is built only from them.
  • Teams that want finished plans ready to publish: each tool returns a structured draft, with placeholders where your inputs gave no fact.
  • Anyone who needs live market or competitor data: the tools do not look anything up. They work from what you type, and anything they add themselves is marked as an example, a suggestion or a placeholder.

How do I use the CRAFT GTM Analyzer tool with an AI assistant?

Add CRAFT GTM to your assistant once (the steps are on Use it in Claude or ChatGPT), then ask in plain words. Here is a prompt built from the tested example:

My role is not stated. Ask me for my role first. Use the CRAFT GTM Analyzer tool in CRAFT GTM. document content: Q1 plan: win 10 new consumer goods brands by running two distributor meets, a LinkedIn campaign for national sales heads and an outbound sequence to heads of sales operations. Owner: marketing lead. Budget: $25K. Success metric: 40 qualified opportunities by 31 March; document type: Quarterly plan. If this tool is unavailable, ask me to open its web page; do not invent its output. In Gemini CLI or Antigravity, use the Helix GTM Suite skills package for related guidance, without claiming to run this connector.

How does the CRAFT GTM Analyzer tool work?

You do not need to sign in. A web browser is enough, and the answer comes back in a second or two.

  1. Fill in the form above, or press Fill in an example.
  2. Press Run CRAFT GTM Analyzer.
  3. Read the result on this page, then copy it and edit it before you use it.

It applies fixed rules in the CRAFT GTM code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the AI assistant connector run the same tool code, so the same input gives the same answer in both.
